# WebCraft — Recurso didáctico para la enseñanza de HTML/CSS

## Resumen

Recurso educativo interactivo construido con la librería **Blockly**, diseñado para introducir a
estudiantes de nivel secundario e inicial en el maquetado y diseño web sin la frustración inicial de
la sintaxis. Mediante el ensamblaje de bloques que representan etiquetas, atributos y estilos, el
estudiante arma la estructura HTML respetando la jerarquía real del documento, mientras la herramienta
genera el código ejecutable y muestra en tiempo real la página web resultante en un panel lateral.

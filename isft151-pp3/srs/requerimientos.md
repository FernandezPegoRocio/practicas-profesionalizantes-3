# Especificación de requerimientos — WebCraft

## Requerimientos funcionales

| Título del requerimiento | Descripción concreta | Responsable | Plazo tentativo | Nivel de prioridad | Estado |
|---|---|---|---|---|---|
| Lienzo interactivo de Blockly | Espacio de trabajo para arrastrar, conectar y configurar los bloques de maquetado y estilo | Rocío | A definir | Muy alta | Pendiente |
| Previsualización en vivo | Renderizar al instante la página web creada por el/la estudiante en un panel lateral | Sylv | A definir | Muy alta | Pendiente |
| Bloques de estructura HTML | Biblioteca de bloques personalizados que representan etiquetas HTML | Rosemary | A definir | Alta | Pendiente |
| Bloques de estilo CSS | Bloques modulares para ajustar propiedades visuales: color de fuente, fondo, márgenes, bordes, alineación de texto y tamaño de fuente | Sylv | A definir | Alta | Pendiente |
| Restricciones de anidamiento | Reglas lógicas de conexión entre bloques (ej.: impedir texto suelto fuera de un contenedor, o `<p>` dentro de `<a>`) | Rosemary | A definir | Alta | Pendiente |

## Requerimientos no funcionales

| Título del requerimiento | Descripción concreta | Responsable | Plazo tentativo | Nivel de prioridad | Estado |
|---|---|---|---|---|---|
| Convención de codificación uniforme | Mantener un único estilo (Upper CamelCase, Lower camelCase o snake_case) de forma coherente en todo el proyecto | Rocío | A definir | Media | Pendiente |
| Indentación consistente | Respetar un mismo estilo de indentación fija (3 o 4 espacios) en todo el código | Rocío | A definir | Media | Pendiente |
| Idioma único en el código | No mezclar inglés/español; trabajar en un único lenguaje de manera consistente | Sylv | A definir | Media | Pendiente |
| Código sin comentarios | El código del repositorio no debe contener comentarios | Rosemary | A definir | Baja | Pendiente |

_Nota: el rol de líder de proyecto es rotativo; reasignar la columna "Responsable" cuando el grupo rote la gestoría._
